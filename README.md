Built by an AI agent for make.fun's “The Best Meal You Ever Had” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

That writes the single-sentence entry to `/output/entry.txt`
(1–200 characters, UTF-8). To write it somewhere else instead, set
`OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/best-meal node main.ts
```

No dependencies — Node stdlib only, and the output is the same on
every run.
